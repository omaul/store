# store

Витрина украшений ручной работы из латуни: https://omaul.github.io/store/

TypeScript + Vite. Деплой на GitHub Pages автоматом на push в `main`.

```bash
npm run dev
npm run build
```

Содержимое сайта — `src/products.ts`, поля и категории описаны в `src/types.ts`.
Фото — `public/assets/items/<изделие>/`, путь в `products.ts` пишется без
`public`. Первый кадр из `photos` стоит в сетке, остальные листаются в карточке.

Контент — фотографии, тексты и дизайн изделий — нет:
[LICENSE-CONTENT](LICENSE-CONTENT), применимое право РФ, короткая версия для
посетителей в разделе «Права» на сайте. Автор изделий и правообладатель

Фото готовим скриптом: ресайз до 1200 px и копирайт в метаданные.

```bash
./scripts/prep-photo.sh originals/DSC_0413.jpg roza/05
```

Оригиналы лежат в `originals/`, папка в `.gitignore` — из истории публичного
репозитория файл уже не убрать, даже если удалить его следующим коммитом. Кадр
квадратный, изделие по центру, фон вырезан или чисто белый, масштаб одинаковый
на всех снимках. Без `brew install exiftool` скрипт пишет только EXIF Copyright и не
вычищает GPS с данными камеры из оригинала.

`public/robots.txt` содержит отказ для сборщиков обучающих данных и заработает
после подключения своего домена: краулеры читают robots.txt только из корня
домена, а на `omaul.github.io/store/` файл им не виден.
