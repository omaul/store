# store

Витрина колец ручной работы из латуни. Статический сайт без сборки, публикуется на GitHub Pages.

Визуально сделан по мотивам [yeezy.com](https://yeezy.com): белый фон, IBM Plex Mono капсом,
сетка вырезанных фото без рамок, никакого декора.

## Что где править

Почти всё содержимое лежит в одном файле — **`js/products.js`**:

- `CONTACT` — ссылка на телеграм или почта для кнопки «написать»
- `FILTERS` — категории в шапке
- `PRODUCTS` — сами кольца (код, название, фото, материал, размеры, цена)
- `INFO` — тексты страниц из футера


Остальное:

```
index.html          — каркас страницы
css/style.css       — стили
assets/rings/       — фотографии колец
.github/workflows/deploy.yml — деплой
```

JS разбит по зонам ответственности, точка входа — `js/app.js`:

```
js/app.js           — подписки на события и первый рендер
js/state.js         — что открыто, какой масштаб и фильтр
js/dom.js           — ссылки на элементы разметки, все в одном месте
js/contact.js       — куда ведут кнопки «написать»
js/grid.js          — сборка сетки под текущий фильтр
js/zoom.js          — число колонок и иконка кнопки слева вверху
js/filters.js       — категории в шапке
js/detail.js        — наезд камеры на изделие и его описание
js/info.js          — текстовые страницы из футера
js/panels.js        — отъезд камеры и закрытие панелей
```

## Фотографии

Сейчас в `assets/rings/` лежат **SVG-заглушки** — векторные силуэты колец, чтобы сетка
не разъезжалась. Замени их на реальные снимки и поправь пути в `products.js`.

Чтобы фото выглядели как на референсе:

- квадратный кадр, кольцо по центру
- фон вырезан (PNG/WebP с прозрачностью) либо чисто белый
- одинаковый масштаб на всех снимках — иначе сетка «прыгает»
- по длинной стороне 1000–1400 px хватит

## Как это работает

- **Зум.** Кнопка слева вверху меняет число колонок: на десктопе `6 → 3`, на телефоне
  `3 → 2 → 1`. На максимальном приближении она превращается в стрелку «назад».
- **Фильтры.** Активный — чёрный, остальные приглушены до `opacity: .2`.
- **Открытие кольца — это наезд камеры, а не новый экран.** Клик по тайлу не создаёт
  вторую картинку: вся сетка сдвигается и масштабируется так, чтобы нажатый тайл
  оказался по центру. Увеличивается тот же самый `<img>`, поэтому фото не
  перерисовывается и не мигает. Остальные тайлы гаснут до `opacity: .1`
  (при одной колонке — до нуля), подписи скрываются, сетка приглушается до `.8`.
  Описание появляется под фото сразу, без проявления. Закрывается кнопкой слева
  вверху, кликом по сетке или `Esc`.
- Цены в сетке не показываются — только в карточке, как на референсе.

## Деплой

Workflow `deploy.yml` запускается на push в `main` и вручную (`workflow_dispatch`).
Артефактом выгружается корень репозитория как есть — сборки нет.

Один раз в настройках репозитория нужно выставить
**Settings → Pages → Build and deployment → Source: GitHub Actions**
(шаг `configure-pages` с `enablement: true` пытается включить это сам, но
на некоторых аккаунтах требуется ручное подтверждение).

Адрес сайта: https://omaul.github.io/store/

> Выгружается **весь корень репозитория**, включая любые случайно закоммиченные папки.
> `temp/` (дамп чужого сайта, лежит локально как референс) закрыт в `.gitignore`.

## Локально

```bash
python3 -m http.server 8765
```

Затем открыть http://localhost:8765/

Сервер обязателен: JS подключён как ES-модуль, а браузер запрещает модулям
загружаться с `file://`. Если открыть `index.html` двойным кликом, страница
останется пустой — в консоли будет ошибка CORS.
